# Query Optimizer Simulator 🚀

An **interactive educational tool** to explore how different algorithms and data structures affect query performance. This project bridges theoretical computer science concepts with practical database query optimization.

---

## 📝 Overview

The **Query Optimizer Simulator** lets users experiment with **search, grouping, and join algorithms** on datasets of various sizes. It visualizes **algorithm performance**, helping users understand execution complexity and optimization trade-offs in database systems.

---

## ⚡ Features

- **Python Simulation Engine**:
  - **Search**: Linear Search (O(n)), Binary Search (O(log n)), Hash Lookup (O(1))
  - **Grouping**: Sorting-based (O(n log n)), Hash-based (O(n))
  - **Join**: Nested Loop Join (O(n²)), Hash Join (O(n + m))

- **Interactive Visualization**:
  - Backend: Matplotlib & Seaborn
  - Frontend: Chart.js (interactive charts)

- **Full Stack Architecture**:
  - Backend: Node.js + Express
  - Database: MongoDB
  - Frontend: React + Tailwind CSS
  - Python integration for simulations

- **Additional Features**:
  - Display Big-O complexity alongside results
  - Export results as CSV or JSON
  - Track experiment history
  - Compare multiple algorithms and dataset sizes
